## 🎮 Features

### 🚗 Drive Vehicles

- Drive cars and explore village roads.
- Rent tractors to work on your fields.
- Ride bicycles and drive trucks.
- Cross bridges and explore the countryside.

### 🏡 Build Homes

- Chop trees and collect wood.
- Gather resources to construct new houses.
- Help expand the village.
- Watch your world grow as you build.

### 🚂 Ride the Train

- Hop aboard the village train.
- Travel between Rainwood Station and Meadow Halt.
- Explore different areas of the world.

### 🌾 Farm and Earn Coins

- Plant wheat, carrots, and pumpkins.
- Water your crops and harvest them when they grow.
- Pick berries and collect roses.
- Sell your resources at the village market.
- Earn coins to buy seeds and rent vehicles.

### 🐓 Explore and Interact

- Feed animals and discover hidden locations.
- Explore more than 100 houses.
- Visit the museum, gallery, town hall, and village office.
- Complete challenges and earn rewards.
- Experience sunny days, rain, and peaceful nights.

### 💞 Meet and Socialize

- Meet villagers and other players.
- Chat with friends in the village.
- Give roses and go on dates.
- Create your own stories and adventures.

## 👥 Multiplayer — Play With Friends

Rainwood Village includes features designed to let you share your adventures.

- 🌍 **Hosted version:** Open the game using the hosted link.
- 🤝 **Play together:** Join friends when multiplayer networking is configured.
- 🔢 **Five-digit invite codes:** The standalone version includes a hosting and joining interface designed for friends on the same Wi-Fi network.
- 💬 **In-game chat:** Communicate with other players.

**Note:** Multiplayer depends on the version and its networking configuration. Opening the same HTML file does not automatically establish an internet multiplayer connection.

## 🕹️ Controls

| Action | Controls |
| --- | --- |
| Move | `W A S D` |
| Look around | Mouse |
| Run | `Shift` |
| Interact, collect, build | `E` |
| Chat | `Enter` |
| Sunny weather | `1` |
| Rainy weather | `2` |
| Night | `3` |
| Mute/unmute sound | `M` |
| Challenges | `C` |
| Help menu | `F1` |
| Menu / Cancel | `Esc` |

### 📱 Mobile Controls

- Use the on-screen joystick to move.
- Use the right side of the screen to look around.
- Tap objects to interact with them.
- Access game features through the on-screen buttons.

## 🚀 How to Play

### Option 1: Play Online

1. Open the Rainwood Village game link.
2. Wait for the game to load.
3. Enter your name and choose your preferred controls.
4. Click the appropriate button to enter the village.
5. Start exploring, building, farming, and driving!

### Option 2: Play Using the HTML File

1. Download the `.html` file from the repository.
2. Open it in a modern web browser.
3. Choose your character and control settings.
4. Enter the village and start playing!

**That's it!** Rainwood Village is designed as a single HTML file, so no traditional game launcher or separate application is required.

Depending on how the file is packaged, an internet connection may still be needed for external libraries, images, or multiplayer services.
